# EMDR Therapy Guide

A private, self-directed EMDR (Eye Movement Desensitization and Reprocessing) web application designed to help reduce the intensity of distressing memories.

## 🔗 Try it Live
**[https://fraterr.github.io/EMDRapp/](https://fraterr.github.io/EMDRapp/)**

---

## What it does

- **Sensory Detailing:** Step-by-step guidance to identify visual, auditory, body, taste, and smell triggers.
- **Bilateral Stimulation:** 1-minute eye-movement tracking with dynamic speed variations and soothing sound chimes.
- **Progress Tracking:** 1-10 distress rating (SUDS scale) evaluation before and after sets.
- **Nervous System Regulation:** Guided deep breathing transitions between sets.
- **Privacy:** 100% client-side. No logins, no databases, no tracking.
